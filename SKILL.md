into the replica/ folder. Stop after each step and ask the user to confirm
before continuing: replica-recon, replica-architect, replica-design,
replica-build, replica-backend, replica-test, replica-diff,
replica-entrepreneur, replica-brand, replica-launch, replica-deploy.
If the user names a step, start there. Never deploy without an explicit go.
